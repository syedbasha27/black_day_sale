# Black Friday Sales Prediction

## Project Overview

This project predicts the purchase amount of customers during Black Friday sales using Machine Learning techniques.

Businesses can use these predictions to understand customer purchasing behavior and improve marketing strategies.

---

## Problem Statement

Predict the purchase amount of a customer based on demographic and purchasing information.

---

## Dataset Information

The dataset contains customer-related information such as:

| Feature | Description |
|----------|-------------|
| Gender | Male or Female |
| Age | Age group of customer |
| Occupation | Occupation category |
| City_Category | Customer city category |
| Stay_In_Current_City_Years | Years spent in current city |
| Marital_Status | Marital status |
| Product_Category_1 | Product category |
| Product_Category_2 | Product category |
| Product_Category_3 | Product category |
| Purchase | Purchase amount (Target) |

## Machine Learning Algorithm

Random Forest Regressor

Why Random Forest Regressor?

- Handles large datasets effectively
- Produces reliable predictions
- Works well with mixed feature types

---

## Project Workflow

1. Load Dataset
2. Handle Missing Values
3. Encode Categorical Features
4. Select Features and Target
5. Split Data into Training and Testing Sets
6. Train Random Forest Regressor
7. Predict Purchase Amount
8. Evaluate Model Performance

---

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

---

## Results

The model predicts customer purchase amounts with reasonable accuracy and helps understand spending patterns during Black Friday sales.
